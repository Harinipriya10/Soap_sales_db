Sales Analysis using SQLite and Python with A Case study on Soap brands


Objective
Use SQL inside Python to analyze basic sales data:
 Total quantity sold per product
 Total revenue per product  
Visualize the results with basic print statements and charts.

Tools Used
• Python 3
• SQLite (via `sqlite3`)
• Pandas
• Matplotlib
• Jupyter Notebook or `.py` script

Dataset
A simulated dataset of soap brand sales, stored in a small SQLite database (`sales_data.db`).  

Each record includes:
• product (e.g., Dove, Lux)
• quantity
• price
• sale_date
